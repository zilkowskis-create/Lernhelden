Lernhelden v8.4 – Deutsch Fix

Verbessert:
- Deutsch zeigt klar getrennt:
  1. Bisherige Deutschübungen
  2. Richtig schreiben
- Richtig schreiben enthält deutlich mehr wechselnde Aufgaben.
- Nach einer richtigen Antwort folgt automatisch nach 3 Sekunden eine neue Aufgabe.
- Bei einer falschen Antwort bleibt die Erklärung sichtbar und „Nächste Aufgabe“ kann manuell genutzt werden.
- Timer wird sauber zurückgesetzt, damit keine doppelten Aufgabenwechsel entstehen.
- PWA-Cache auf v8.4 erhöht.
